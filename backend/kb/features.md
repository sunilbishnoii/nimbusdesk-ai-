# Product features
## Shared inbox
The shared inbox collects customer emails, chat messages and social messages in one place. Agents can assign, tag and prioritise tickets, and add private notes for teammates.
## Ticket automation
Ticket automation lets you create rules that route, tag and reply to tickets automatically based on keywords, customer plan or working hours. Automation is available on the Growth and Enterprise plans.
## Live chat widget
The live chat widget can be added to any website with a single script tag. It supports offline forms, pre-chat questions and file sharing.
## Analytics dashboard
The analytics dashboard reports first response time, resolution time, ticket volume and customer satisfaction scores. Reports can be exported as CSV and scheduled by email. Analytics is included in Growth and Enterprise.
## AI reply suggestions
AI reply suggestions draft answers for agents using your help centre articles. Agents always review a suggestion before sending it. The feature is included in Growth and Enterprise.
## Knowledge base
The knowledge base lets you publish help centre articles in multiple languages and link them to tickets and chat replies.
