# Integrations and API
## Available integrations
NimbusDesk integrates with Slack, Gmail, Outlook, Salesforce, HubSpot, Shopify and WhatsApp Business. Integrations can be switched on from the settings page without any coding.
## REST API and webhooks
A REST API and webhooks let you connect NimbusDesk to your own systems. The API rate limit is 100 requests per minute on Growth and 1000 requests per minute on Enterprise. The API is not available on the Starter plan.
