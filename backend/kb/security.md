# Security and compliance
## Data protection
All customer data is encrypted in transit using TLS 1.2 or higher and at rest using AES-256. Access is controlled with role-based permissions, and two-factor authentication is available on every plan.
## Data residency
Customers can choose to store data in the United States, the European Union or India. The region is selected when the workspace is created and cannot be changed afterwards without a migration.
## Single sign-on and audit logs
Single sign-on using SAML and detailed audit logs are available on the Enterprise plan only.
## Compliance
NimbusDesk follows GDPR requirements and offers a data processing agreement on request. Customers can export or delete their data at any time.
